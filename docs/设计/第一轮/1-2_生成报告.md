# 1-2 · 功能二：生成 preset 报告

## 目标

**导入进来的数据，要能直接变成用户看得懂的账单页面。**

按「支出 / 收入 × 周 / 月 / 年」出固定格式的报表，包含：

- **小结** —— 本期合计、环比变化、笔数、每日日历、趋势柱状图
- **分类** —— 大类环形图 + 大类小类二级列表（按金额排序）
- **支出方式** —— 按支付渠道分组（花呗 / 银行卡 / 亲情卡…）
- **收入排行** —— 收入交易按金额降序

## 用的时候注意一件事

**页面默认停在当月。** 账单通常只导到上个月，所以新打开页面看到的是 `¥0.00`，
这不是坏了 —— 点左上角 `‹` 翻到上一个有数据的月份。

## 交给队友决策的部分

**后端保证「数字能算出来」，但「怎么呈现」是队友的事。**

已经做完的：版面、趋势图、日历、分类环形图、支出方式、明细列表，以及分类下钻。

仍需决策的：

| 问题 | 说明 |
|---|---|
| 还要什么交互 | 下钻、筛选、导出、对比，目前是最小可用形态 |
| 数字怎么显示 | 后端保证：金额是元、两位小数；占比是百分数（`17.2` = 17.2%）；空列表是 `[]` 不是 `null` |
| 分类太粗怎么办 | 现在直接用平台原始分类（比如 78 笔都是「商户消费」）。要不要拆、怎么拆，是产品决策 |
| 小类为空 | 后端第一轮不返回小类（`minors` 为空数组），分类展开后是空的 |
