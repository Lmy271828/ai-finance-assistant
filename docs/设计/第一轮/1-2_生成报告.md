# 1-2 · 功能二：生成 preset 报告

## 目标

**导入进来的数据，要能直接变成用户看得懂的账单页面。**

按「支出 / 收入 × 周 / 月 / 年」出固定格式的报表，包含：

- **小结** —— 本期合计、环比变化、笔数、每日日历、趋势柱状图
- **分类** —— 大类环形图 + 大类小类二级列表（按金额排序）
- **支出方式** —— 按支付渠道分组（花呗 / 银行卡 / 亲情卡…）
- **收入排行** —— 收入交易按金额降序

## 交给队友决策的部分

**后端保证「数字能算出来」，但「怎么呈现」是队友的事。**

需要队友自己判断的：

| 问题 | 说明 |
|---|---|
| 页面长什么样 | 目前只有骨架，`data-component` 标好了各区块的位置 |
| 这些计算适配吗 | 环形图、柱状图、日历，ECharts 都能画，但要不要加交互、怎么排版，队友定 |
| 数字怎么显示 | 后端保证：金额是元、两位小数；占比是百分数（`17.2` = 17.2%）；空列表是 `[]` 不是 `null` |
| 日历缺日期怎么补 | 后端不返回无消费的日期，前端自己补零渲染 |
| 分类太粗怎么办 | 现在直接用平台原始分类（比如 380 笔都是「商户消费」）。要不要拆、怎么拆，是产品决策 |
