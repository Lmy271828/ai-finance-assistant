# 账单页面设计

> 文档目的：说清楚账单页面长什么样、有哪些组件、组件之间的层级关系。
> 不涉及字段设计和数据库 Schema，单独见《原始账单格式》。

---

## 一、整体结构

```
┌─────────────────────────────────────┐
│  顶部导航栏                           │
│  [←]  [支出 / 收入  Toggle]  [···]  │
├─────────────────────────────────────┤
│  时间选择器（三联动）                   │
│  [周▼]  [月▼]  [年▼]  当前选中：9月   │
├─────────────────────────────────────┤
│                                     │
│  主内容区                            │
│  （支出/收入 × 小结/分类/支出方式/排行）  │
│                                     │
└─────────────────────────────────────┘
```

**路由**：`/bill?type=expense&period=month&month=2026-09&tab=summary`

---

## 二、顶部导航栏

| 元素 | 行为 |
|---|---|
| 返回键 `←` | 返回上一页 |
| 支出 / 收入 Toggle | 点击切换大页面，重置 tab=summary |

---

## 三、时间选择器

三级同时显示，激活的粒度高亮：

| 粒度 | 按钮 | 选择后 |
|---|---|---|
| 周 | `[周▼]` | 弹出年份→周数列表（如 2026年第38周） |
| 月 | `[月▼]` | 弹出月份列表（如 2026年9月） |
| 年 | `[年▼]` | 弹出年份列表（如 2026年） |

切换粒度 → 时间值重置为最近一个有数据的区间。

---

## 四、支出页面

### 4.1 小结

#### 每日日历（周视图 + 月视图）

以日历网格展示每天支出金额：

```
  日   一   二   三   四   五   六
 ┌──┬──┬──┬──┬──┬──┬──┐
 │3日│4日│5日│6日│7日│8日│9日│  ← 第一周
 │120│ 85│200│  0│150│  0│ 90│
 └──┴──┴──┴──┴──┴──┴──┘
 ┌──┬──┬──┬──┬──┬──┬──┐
 │10日│...                      ← 第二周
```

- 有消费的日期：蓝色圆角方块，日期粗体，金额细体
- 无消费：留空或灰色"－"
- 今天：深蓝圆形背景
- 点击任意日期 → 跳转 Transactions 页面，带 `date=YYYY-MM-DD` 筛选

#### 周期总览

| 指标 | 展示 |
|---|---|
| 总支出 | 该周期支出 sum，例：¥3,573.67 |
| 较上周期变化 | 绝对值 + 百分比，例：-¥900.00 ↓ |
| 支出笔数 | 共 N 笔 |

#### 月度小结（仅月视图额外显示）

**柱状图**：近5个月支出对比
- 5根柱子（近5月），当前月高亮
- 月均参考线：虚线 + 数值标注

**日历热力图**：当月每日支出（与周视图日历结构相同，但只显示当月）

---

### 4.2 分类

#### 第一层：大类环形图

以环形图（饼图变体）展示各大类占比：

```
       餐饮美食
        42.1%   ← 扇形高亮时中心显示分类名+金额+占比
      ╱      ╲
     ╱  交通   ╲
    │   9.5%   │
     ╲   购物  ╱
      ╲  7.9%╱
       ─────
```

点击扇形 → 高亮该分类，展开其子类列表。

#### 第二层：分类列表（按金额降序）

```
餐饮美食   ¥800.00   42.1%   ▲
  美团        ¥300.00   15.8%
  某快餐      ¥200.00   10.5%
  便利店      ¥395.00  11.1%
交通出行   ¥341.20    9.5%   ▶
购物       ¥150.00    7.9%   ▶
```

- 点击 `▲`/`▶` 或整行 → 展开/收起子类
- 点击子类名 → 跳转 Transactions 页面，带 `category=该子类` 筛选
- 大类无子类的直接跳转

> 大类由 `tx_type` 映射而来，映射规则写在配置文件里，可调整。

---

### 4.3 支出方式

按支付渠道分组展示：

```
花呗              ¥500.00   6笔   ▶
[银行]储蓄卡([尾号])  ¥300.00   1笔   ▶
亲情卡([亲友A])     ¥300.00  11笔   ▶
小荷包              ¥20.00   1笔   ▶
```

点击 `▶` → 展开该支付方式下的所有交易流水列表（Transactions 页面，带 `pay_method=该方式` 筛选）。

## 五、收入页面

### 5.1 小结

结构与支出小结完全一致，区别仅在于：
- 范围限定为 `direction`='收入'
- 月度柱状图改为近5月**收入**对比
- 无"大额消费"等额外模块

---

### 5.2 收入排行

按 `amount` 降序排列所有收入交易：

```
🥇 1   ¥800.00   09-06 14:49   转账-[亲友A]       转账红包
🥈 2   ¥500.00   09-12 23:24   转账-[亲友B]       转账红包
🥉 3   ¥300.00   09-10 19:16   [雇主]               工资
```

点击任意一行 → 跳转该笔交易详情（或 Transactions 页面，带 `id=该笔id`）。

---

## 六、Transactions 页面（从任意入口跳转的明细页）

作为所有跳转的承接页，始终可访问：

```
/transactions?date=2026-09-06
/transactions?month=2026-09&category=餐饮
/transactions?pay_method=花呗
```

默认显示：当前周期（由 URL 参数决定）、按时间倒序排列的所有流水。
